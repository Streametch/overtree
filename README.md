# overtree
Оверлей для Windows Проводника

Основная идея, упростить навигацию по папкам файловой системы через встроенный Проводник Windows. Иметь возможность заранее просмотреть глубину папок и их имена, а так же выполнить поиск по дереву и сразу перейти в нужный каталог. 
Фичи:
Follow mode -  режим  отрисовки дерева в реальном времени по выбраному каталогу в проводнике
Поиск - живой поиск по имени каталогов в дереве с отображением его ветки 
Автоскрытие окна при неактивности, повторный вызов комбинацией shift+ctrl+t в проводнике
Возможность задать глубину прорисовки дерева каталога
Возможность подсчитать количество файлов в папках
В зависимости от глубины дерева - зависит цвет 
Активация/деактивация строки поиска правым кликом по нижнему краю окна оверлея
Быстрый скрол по динамическим точкам вверху/внизу оверлея.
