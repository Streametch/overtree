# overtree
*Оверлей для Windows Проводника*

Основная идея, упростить навигацию по папкам файловой системы через встроенный Проводник Windows. Позволяет заранее просмотреть глубину папок и их имена, а так же выполнить поиск по дереву и сразу перейти в нужный каталог. 

### Фишки:

- **Follow mode** -  режим  отрисовки дерева в реальном времени по выбраному каталогу в проводнике

- **Поиск** - живой поиск по имени каталогов в дереве с отображением его ветки 

- **Автоскрытие** окна при неактивности, повторный вызов комбинацией shift+ctrl+t в проводнике

- Возможность задать **глубину прорисовки дерева** каталога

- Возможность подсчитать **количество файлов** в папках

  ### Интерфейс:

- Каждая ветка в зависимости от глубины имеет свой цвет.

- Активация/деактивация строки поиска правым кликом по нижнему краю окна оверлея

- Быстрая перемотка по динамическим точкам вверху/внизу оверлея. 

- Есть возможность увеличить размер окна :smile:

### Как использовать:

Программа запускается через `overtree_start.exe` и работает в паре с  Проводником Windows.

Комбинация `ctrl+shift+t` в окне проводника, отображает окошко overtree

По умолчанию дерево  выбранного каталога обновляется повторным нажатием `ctrl+shift+t`, то есть обновление и/или отображение по запросу, а не автоматически. Данный режим экономит ресурсы системы.

Если включить в настройках **режим Follow** - overtree будет обновлять дерево папок автоматически, следуя за каталогами в Проводнике Windows.

Поиск можно включать не заходя в настройки - клик ПКМ по нижнему краю окна оверлея.

Точка в нижнем правом углу, это хинт для изменения размера окна - *удерживайте точку мышью и размер окна можно изменить.*

Если листинг большой, при пролистывании появляются динамические точки, по ним можно ориентироваться в каком месте списка вы находитесь. По этим точкам в листинге можно перемещаться, кликая на них.

Что бы принудительно скрыть overtree - нажмите ESC. 

Если нашли нужную папку в дереве - можно сразу по ней кликнуть что бы открыть в Проводнике.

Программа создавалась  с минималистичным интерфейсом, по этой причине у неё нет встроенной справки или выбора языков *(пока что)*

**Важно!** Для выхода из overlay используйте меню *Выход* из настроек.
